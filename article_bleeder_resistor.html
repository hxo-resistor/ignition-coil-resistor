高压电容泄放电阻怎么算？绕线电阻vs玻璃釉电阻的技术对比

高阻值绕线电阻 · 技术解析 · 2026年9月

高压电容在断电后仍可能储存致命电荷。泄放电阻是保障维修人员安全的必要元件。正确计算阻值和功率是关键。

一句话总结：HXO HVW系列高阻值绕线电阻，阻值0.1Ω~651kΩ，功率1W~50W，适用于变频器制动、新能源高压系统泄放。

一、泄放电阻的设计原则

阻值计算

泄放电阻的核心任务是在安全时间内将电容电压降至安全水平。

V(t) = V₀ × e^(-t/RC)

其中：
V(t) = t时刻的电压
V₀ = 初始电压
R = 泄放电阻阻值
C = 电容容量
t = 时间

安全标准：IEC 61010规定，断电后1秒内电压应降至60V以下。

示例计算

已知：电容 100μF，初始电压 400V，目标电压 60V（1秒后）

R ≤ -t / (C × ln(V/V₀))
= -1 / (100×10⁻⁶ × ln(60/400))
= -1 / (0.0001 × -1.833)
≤ 545kΩ

建议选择：100kΩ ~ 470kΩ范围内

功率计算

瞬时功率：P(t) = V(t)² / R = V₀² × e^(-2t/RC) / R

初始功率（最恶劣情况）：P₀ = V₀² / R

示例：V₀ = 400V, R = 100kΩ
P₀ = 400² / 100000 = 1.6W

建议：选择额定功率为计算值的2倍以上
